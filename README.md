# Eletrônica Digital NH

Plataforma web moderna para a **Eletrônica Digital NH**, especialista em manutenção eletrônica em Novo Hamburgo — RS com mais de 30 anos de experiência.

## 🎯 Sobre

A Eletrônica Digital NH oferece assistência técnica autorizada para:
- **Smart TVs & Televisores** — Reparo em todas as marcas (Samsung, LG, Sony, Philips, AOC)
- **Som Automotivo** — Módulos amplificadores, fontes e centrais multimídia (SounDigital, Stetsom, Taramps, JFA, Machine)
- **Micro-ondas** — Manutenção completa em todas as marcas
- **Eletrônica Automotiva** — Diagnóstico e reparo de injeção eletrônica (Planatc, KXTRON, Kitec)
- **Carregadores & Fontes** — Assistência autorizada (Kitec, Datrel)
- **Manutenção Geral** — 30 anos de experiência em diversos aparelhos eletrônicos

## 🚀 Tecnologias

- **React 19** — Framework moderno para UI interativa
- **TypeScript** — Tipagem estática para maior segurança
- **Tailwind CSS 4** — Estilização responsiva e utilitária
- **Vite** — Build tool rápido e eficiente
- **Wouter** — Roteamento client-side leve
- **shadcn/ui** — Componentes UI acessíveis e customizáveis

## 📁 Estrutura do Projeto

```
client/
  ├── public/           # Arquivos estáticos (favicon, robots.txt)
  ├── src/
  │   ├── pages/        # Páginas da aplicação

  │   ├── lib/          # Funções utilitárias

  │   ├── main.tsx      # Entry point
```

## 🎨 Seções do Site

1. **Hero** — Apresentação da empresa com call-to-action
2. **Serviços** — 6 categorias de serviços oferecidos
3. **Assistência Técnica Autorizada** — Carrossel animado das marcas parceiras
4. **Nossas Parcerias** — Descrição detalhada de 9 empresas parceiras
5. **Quem Somos** — História, missão e estatísticas da empresa
6. **O que vamos consertar hoje?** — Formulário interativo com integração WhatsApp

8. **Footer** — Navegação e informações de contato

## ✨ Funcionalidades

- ✅ **Responsivo** — Funciona perfeitamente em mobile, tablet e desktop
- ✅ **Formulário Expandível** — Selecione o serviço e preencha marca, modelo e defeito
- ✅ **Integração WhatsApp** — Envie mensagens pré-preenchidas diretamente para o WhatsApp
- ✅ **Carrossel Animado** — Marcas autorizadas passam em animação contínua
- ✅ **Mapa Interativo** — Google Maps integrado com localização da empresa
- ✅ **Navegação Suave** — Links internos com scroll suave
- ✅ **Design Moderno** — Interface limpa e profissional com cores azul/verde

## 🛠️ Desenvolvimento

### Requisitos
- Node.js 22+
- pnpm 10+

### Instalação

```bash
# Clonar repositório
git clone https://github.com/LuquinhasBohrer/Eletronica-Digital.git
cd Eletronica-Digital

# Instalar dependências
pnpm install

# Iniciar servidor de desenvolvimento
pnpm dev
```

O site estará disponível em `http://localhost:3000`

### Build para Produção

```bash
pnpm build
pnpm start
```
